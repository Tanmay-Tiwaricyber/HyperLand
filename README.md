# HyperLand for Windows

### iOS 26-inspired Liquid Glass Dynamic Island for Windows

**Hyper Island** brings a modern, interactive Dynamic Island experience to Windows with Liquid Glass visuals, swipeable pages, media controls, notifications, productivity tools, wellness tracking, system controls, and much more.

Built as a **Windhawk mod** and designed to feel like a native part of Windows while keeping the experience lightweight and customizable.

![Hyper Island](https://raw.githubusercontent.com/Tanmay-Tiwaricyber/Hyper-Island/banner.png)

---

## ✨ Features

### 🏝️ Dynamic Island

A compact, interactive island that expands into a full control center.

- Interactive top-center island
- Expandable control center
- Click-through overlay when inactive
- Smooth expand/collapse animations
- Bouncy spring motion
- Hover interactions
- Multi-monitor support
- Custom position and scaling
- Always-on-top option

---

## 🧊 Liquid Glass

Hyper Island is designed around an iOS 26-inspired **Liquid Glass** interface.

- Real blur-behind effect
- Saturation enhancement
- Glass tint
- Specular rim
- Inner edge glow
- Diagonal caustic highlights
- Top-lit glass sheen
- Cursor-following light
- Floating shadow
- Animated light sweep
- Multiple backdrop styles

Liquid Glass effects and spring animations can be enabled or disabled from the settings.

# 🔔 Notifications

Hyper Island can showcase Windows notifications directly through the island.

When a notification arrives:

- A notification banner appears
- App name is displayed
- Notification title/body is shown
- Clicking the island opens the Alerts page
- Open notifications directly
- Dismiss individual notifications
- Clear all notifications

---

# 📁 File Shelf

Drag files or folders directly onto Hyper Island.

The **File Shelf** temporarily keeps references to your files without moving them.

### Actions

- 📂 Open file
- 📁 Show in Explorer
- 📋 Copy to clipboard
- ❌ Remove from shelf

> Files are referenced, not moved or duplicated.

This makes it easy to temporarily collect files and paste them somewhere else using `Ctrl + V`.

# 🎵 Universal Media Controls

Control media directly from Hyper Island.

Supported sources include:

- Spotify
- Chrome
- Microsoft Edge
- Firefox
- Apple Music
- Windows media sessions
- VLC
- Games and other audio applications

Players using Windows media controls are detected automatically.

For applications that do not expose media controls, Hyper Island can detect active audio output and provide fallback controls.

### Media controls

- Previous
- Play / Pause
- Next
- Current application
- Album artwork
- Live waveform
- Application brand color

---

# 🔊 Per-App Volume Mixer

Control individual applications without opening the Windows volume mixer.

Each active audio application gets its own volume slider.

### Features

- Individual volume control
- Per-app mute
- Active application detection
- Audible applications move to the top
- Visual activity indication
- Application-specific colors
